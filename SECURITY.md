# Security & Privacy Notes

- Do not store full addresses or photos by default. If you enable logging, hash PII and rotate logs.
- Validate and strip EXIF/location from images before sending to the model.
- Enforce per-IP + per-session rate limit to prevent abuse.
- Add CAPTCHA or email-gated access if you see bot traffic.
- Display a non-legal disclaimer: planning guidance only, not a contractor quote.
